燈條焊點實驗室

燈條從焊接、檢查到通電測試，這一頁都整理好了。按按鈕、切開關，看看焊錯時 Arduino 和燈條會發生什麼事。

焊接→三嗶檢查→插上測試治具→看測試燈判讀→裝上無人機
焊接技巧 三嗶檢查 短路模擬 測試燈判讀 接反會怎樣 測試治具 加工圖 測試程式
STATION 1・焊接

小燈條為什麼特別容易短路

我們的燈條很窄，三個焊點排成三角形：上面是 + 和 −，下面中間是訊號點。線都從同一端進來，焊上排的線一定會經過訊號點旁邊，錫多一點就連在一起了。

燈條上的箭頭要從 JST 接頭這端往外指。焊到另一端（DOUT 出口）的話，整條都不會亮。

步驟 1兩邊都先上錫

焊點先上一點錫，線頭也先上錫。之後壓在一起，用烙鐵碰一下就好，不要另外再加錫。

步驟 2先焊下面的訊號點

訊號線貼平、往外拉，上排兩條再從兩側進來，三條線就不會交叉。

線頭裸銅只留 1～2mm

外皮剝太長，露出來的銅線最容易碰到旁邊的焊點。

線材用 26～28AWG 細矽膠線

線太粗不好焊，也容易把小焊點整片拉起來。

隔開Kapton 膠帶當隔牆

焊點之間貼一條細的 Kapton，耐熱 260°C 以上。藍色矽膠焊接墊約耐 500°C，PLA 約 60°C 就軟了，不能讓烙鐵碰到。

收尾透明熱縮管取代電火布

能絕緣也能固定線，透明的看得到焊點，而且不會留下黏膠殘留。

三用電表三嗶檢查

STATION 5・原理

V、G 接反：普通 LED 沒事，WS2812 有風險

普通 LED 接反只是不亮。WS2812 每顆燈珠裡還有一顆控制晶片，晶片的電源腳之間藏著一顆保護用的二極體。平常它是反向、不導通的；V、G 一接反就變成順向導通，等於電流直接穿過晶片短路。

會不會燒掉，要看電源能給多少電流

接在哪裡接反結果
測試治具（Leonardo USB，有 500mA 保險絲）通常救得回來電流被限制，又分散到 30 顆燈；及時拔掉多半沒事。最靠近接頭的第 1 顆最容易受傷。
沒有保險絲的相容板有風險電流沒被限制，靠近接頭的燈珠可能燒掉。
無人機電池或飛控 5V很可能燒毀電流可以到好幾安培，晶片幾秒內就過熱。

所以：每條燈條的 JST 腳位順序都要一致。在測試台插上去是正常的，裝到飛機上才不會接反。

照線色接，不要照位置接。我們的 JST 接頭線序是紅、黑、黃，中間那支腳是黑線 GND。電阻要串在黃線（訊號）上，串到中間會串錯。

做好後用三用電表確認：JST 黃線那支腳量到 D6 約 220Ω，紅線通 5V，黑線通 GND。電阻兩端套熱縮管。

供電與保護

V（電源線）不能串電阻，燈條會沒電。改靠正版 Leonardo USB 上的 500mA 自恢復保險絲。相容板要看 USB 接頭旁有沒有標 F1 的小零件。
S（訊號線）串 220Ω，短路時電流約 20mA，D6 安全。
電腦 USB可以。V–G 短路時會聽到 USB「叮咚」斷線聲。
USB 充電頭可以，5V 1A 以上。快充頭也沒問題（Arduino 不會協商升壓）。
行動電源不建議。電流太小會自動關機，測到一半斷電。
DC 頭／VIN不要用，電流不會經過那顆保險絲。

步驟 1剪線、剝線

JST 線留約 10 cm，杜邦線剪掉一頭也留約 10 cm。線頭剝 5mm，先上錫。

步驟 2先套熱縮管！

焊之前就把 2mm 熱縮管套進線裡（選配的大熱縮管也先套）。焊完才發現忘了套，就得剪掉重來，這是最常犯的錯。

步驟 3焊紅線、黑線

JST 紅線接 5V 那條杜邦，JST 黑線接 GND 那條。兩條線頭並排或互鉤後再焊。

步驟 4黃線串電阻

電阻兩腳各剪到約 8mm、彎成鉤：一頭接 D6 杜邦線，一頭接 JST 黃線。電阻沒有正負，哪頭都可以。做 v4 的話，A0 線一起焊在電阻靠 JST 那一頭。

步驟 5熱縮、貼標籤

把熱縮管推到焊點上吹熱，電阻要整顆包住。杜邦頭貼上 5V／GND／D6。

步驟 6用電表驗收

照下表量一次，全部對才能用。最後插上一條好的燈條跑 v3.2 確認。

驗收：三用電表量這些

量哪兩點應該讀到不對的話
JST 紅 ↔ 杜邦 5V約 0Ω（嗶）焊點沒焊上，或接錯線
JST 黑 ↔ 杜邦 GND約 0Ω（嗶）同上
JST 黃 ↔ 杜邦 D6約 220Ω（不會嗶）讀到 0Ω：電阻被跳過；讀到 OL：電阻沒焊上
JST 紅↔黑、紅↔黃、黑↔黃OL治具線自己短路，拆開熱縮管檢查
插上一條好燈條，從燈條焊點量回杜邦頭V↔5V、G↔GND 約 0Ω，S↔D6 約 220ΩJST 對接時線序交叉了（有些現成對接線兩端顏色不對應）
STATION 7・程式

LEDv3.2 測試程式

測試治具用的 Arduino 程式。燒進 Leonardo 一次，之後插上燈條就會自動跑測試。

LEDv3.2 程式

Arduino IDE 需先安裝 Adafruit NeoPixel 函式庫。Uno、Nano、Leonardo 都可以用。

展開程式碼 
#include <Adafruit_NeoPixel.h>

// 足球無人機 LED 燈條測試器 v3.2（三色分段＋白燈數量指示＋跑馬燈）
// 第 1 段：開頭亮 1 顆白燈；第 2 段：開頭亮 2 顆白燈；第 3 段：開頭亮 3 顆白燈
//   → 數白燈有幾顆，就是第幾段（白色不管哪種色序看起來都是白的）
// 把第 1、2、3 段「其他燈」看到的顏色照順序念出來 = 燈條色序
//   綠 紅 藍 → GRB（原廠）；紅 綠 藍 → RGB（副廠）

#define LED_PIN     6
#define NUM_LEDS    30
#define BRIGHTNESS  40
#define COLOR_MS    2000
#define GAP_MS      400
#define CHASE_MS    60
#define LOOP_GAP_MS 1000

// 刻意用 NEO_RGB：參數照順序原樣送出，第幾段 = 第幾個位元組
Adafruit_NeoPixel strip(NUM_LEDS, LED_PIN, NEO_RGB + NEO_KHZ800);

void blank(int ms) {
  strip.clear();
  strip.show();
  delay(ms);
}

// 第 seg 段（1～3）：全部燈只送第 seg 個位元組，開頭 seg 顆改成白燈當指示
void showStep(int seg) {
  uint8_t a = (seg == 1) ? 255 : 0;
  uint8_t b = (seg == 2) ? 255 : 0;
  uint8_t c = (seg == 3) ? 255 : 0;
  Serial.print("第 "); Serial.print(seg); Serial.println(" 段：開頭 " + String(seg) + " 顆白燈");
  for (int i = 0; i < NUM_LEDS; i++) strip.setPixelColor(i, a, b, c);
  for (int i = 0; i < seg; i++) strip.setPixelColor(i, 255, 255, 255);   // 指示燈：亮 seg 顆白燈
  strip.show();
  delay(COLOR_MS);
  blank(GAP_MS);
}

void showWhite() {
  Serial.println("第 4 段：全白（三色同時亮）");
  for (int i = 0; i < NUM_LEDS; i++) strip.setPixelColor(i, 255, 255, 255);
  strip.show();
  delay(COLOR_MS);
  blank(GAP_MS);
}

void chase() {
  Serial.println("跑馬燈：白燈從第 1 顆跑到最後一顆");
  for (int i = 0; i < NUM_LEDS; i++) {
    strip.clear();
    strip.setPixelColor(i, 255, 255, 255);
    strip.show();
    delay(CHASE_MS);
  }
}

void setup() {
  Serial.begin(115200);
  pinMode(LED_BUILTIN, OUTPUT);
  strip.begin();
  strip.setBrightness(BRIGHTNESS);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);   // L 燈亮 = 一輪的開頭（保留）
  showStep(1);
  digitalWrite(LED_BUILTIN, LOW);
  showStep(2);
  showStep(3);
  showWhite();
  chase();
  blank(LOOP_GAP_MS);
}
中正國中創客社・足球無人機環燈測試。數值為一般 ATmega 板子的典型值，實際以零件規格為準。
